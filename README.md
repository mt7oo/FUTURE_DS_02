# Customer Retention & Churn Analysis 

## Project Overview
This project focuses on customer retention and churn analysis for a subscription-based business using Power BI. The goal of the analysis is to identify churn patterns, customer retention trends, and business factors affecting customer loyalty.

The dashboard provides actionable insights that can help businesses improve customer retention strategies and reduce churn-related revenue loss.


## Key Metrics Analyzed
- Total Customers
- Customer Churn Rate
- Revenue Lost Due to Churn
- Average Customer Tenure

## Dashboard Features
- Churn distribution analysis
- Contract type churn analysis
- Payment method analysis
- Internet service churn insights
- Interactive slicers and filters
- Customer retention insights
- Business recommendations


## Key Insights
- Month-to-month contract customers show the highest churn rate
- Customers using fiber optic internet services churn more frequently
- Electronic check payment users have higher churn behavior
- Long-term contracts improve customer retention significantly


## Business Recommendations
- Promote yearly subscription plans through discounts
- Improve onboarding experience for new users
- Introduce loyalty rewards for long-term customers
- Target high-risk customers with personalized retention campaigns
